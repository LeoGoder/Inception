# Inception

## Connection

Connect to the vm with the simple and SSH connection AND with the  graphical export

classic ssh:
```sh
ssh lgoderne@127.0.0.1 -p 2222
```
or
```sh
ssh lgoderne@localhost -p 2222
```

Graphical export:
```sh
ssh -X lgoderne@127.0.0.1 -p 2222
```
or
```sh
ssh -X lgoderne@localhost -p 2222
```
